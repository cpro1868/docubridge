# DocuBridge v1 版本摘要

> 日期：2026-04-11

## 当前一句话状态

DocuBridge 已经进入 `v1.0 beta` 候选阶段，核心双向文档链路和模板定制能力已经成型。

## 当前可对外表达的能力

- 支持 `Word (.docx) -> Markdown`
- 支持 `Markdown -> Word (.docx)`
- 支持 YAML 样式配置
- 支持 `.docx` 模板协同渲染
- 支持模板场景下的诊断与样式解释

## 当前不应过度承诺的能力

- 高级 Word 多级编号系统
- 复杂分页、节、目录、页眉页脚恢复
- `.xlsx/.pptx/.pdf` 作为首发主卖点
- GUI
