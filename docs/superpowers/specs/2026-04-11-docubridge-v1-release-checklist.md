# DocuBridge v1 发布检查清单

> 日期：2026-04-11  
> 状态：发布前收口中  
> 适用版本：`v1.0`

## 1. 发布范围

`v1.0` 只以以下能力作为发布阻塞项：

- `Word (.docx) -> Markdown`
- `Markdown -> Word (.docx)`
- YAML 样式配置
- `--template` 模板协同
- CLI 可用性
- README 与最小示例

以下能力不阻塞 `v1.0`：

- `.xlsx -> markdown`
- `.pptx -> markdown`
- `.pdf -> markdown`
- `batch`
- GUI

## 6. 当前已知边界

以下不是 bug，而是当前版本的明确边界：

- 列表当前使用段落样式加文本前缀方式渲染，不是原生 Word 多级编号系统
- 代码块当前渲染为单列表格，其视觉效果受单元格段落样式影响
- 模板协同当前聚焦样式与宿主文档，不覆盖复杂节、页眉页脚、目录、分页和高级编号定义
- 图片存在时会插入，缺失时会回退为占位段落
- `.xlsx/.pptx/.pdf` 不作为 `v1.0` 发布阻塞项
